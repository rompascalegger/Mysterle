# Mysterle

Too much is happening and nobody knows why. The game is to understand the game.

Plain HTML, CSS and JavaScript, no build step, no dependencies (same setup as Dicele).
One new mystery every day: nine layers, each with a big sentence you can tap, drag or rewrite.

Buttons: ? hint (costs you), ☾ calm mode (less flashing and motion), ♪ sound.

## Run locally

```bash
python -m http.server 8124
```

<details><summary>Spoilers</summary>

1. Tap words to make the instruction easier (e.g. ONE BLUE CIRCLES).
2. DO NOT TOUCH ANYTHING: wait 7 s (or change NOT to NOW and click).
3. YOU CAN NOT WIN: drag NOT out, or make it CAN'T NOT.
4. THERE ARE … : make the sentence true (eyes count, ZERO MOUTHS, MANY STARS).
5. THE DOOR IS CLOSED: say OPEN, then click the door.
6. THE ANSWER IS NOT HERE: the word is in the tab title / visible in calm mode; type it.
7. FIND THE QUIET: follow the calm, or BE QUIET, or MAKE NOISE.
8. CLICK ON THE BEAT: tap with the eye's pulse.
9. THIS GAME IS ABOUT: WORDS, UNDERSTANDING or CHANGING THE RULES.
</details>
